Günəş simulyatoru: adi PV, optik qat və CPV

Eyni işıqtoplama sahəsində (apertura) dörd ssenarinin illik enerjisi. Sürgüləri dəyişin: 8760 saatlıq hesab brauzerdə yenidən aparılır və Python modeli ilə eyni nəticəni verir (paritet testi). Brüt = modulun DC çıxışı; xalis = brüt − izləmə − idarəetmə − soyutma sərfi.

B və C üzrə optika, fotoelement, soyutma və izləmə rəqəmləri fərziyyədir. Prototip ölçüsü və ya kommersiya məhsulu haqqında nəticə deyil.

Fərziyyə dəsti


    


    

      

      


      

        
İllik enerji: brüt və xalis, kWh/m² apertura

          
Ədalətli cütlər: sabit A ↔ sabit B; iki oxlu A-izləmə ↔ iki oxlu C. Açıq zolaq — brüt DC, dolu zolaq — xalis.

        

      


      

        

          
Aylıq xalis enerji, kWh/m² apertura

          

          

          
Aylar yerli standart vaxtla (yay saatı olmadan). Ayların cəmi illik xalis enerjiyə bərabərdir.

        

        

          
Hava sinifləri üzrə brüt DC, kWh/m² apertura

          

          
Siniflər DHI/GHI payına görədir və yalnız GHI > 10 W/m² olan saatları əhatə edir. Qalan saatlar ayrıca sətirdədir, cəm illik enerjiyə bərabərdir.

        

      


      

        
CPV başabaş xəritəsi: optik ötürmə × fotoelement səmərəliliyi

          
Rəng: C / A-izləmə illik xalis nisbəti. Bütöv xətt — A-izləmə ilə bərabərlik, qırıq — sabit A ilə. Ştrixli xanalar: model etibarlılıq diapazonundan çıxır.

        
        

      


      

        
Əvvəlki model (v1) ilə müqayisə — reqressiya bazası
