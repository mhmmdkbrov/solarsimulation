Optik simulyator

Optikanı seçin, parametrlərini daxil edin, qəbuledicini və montajı seçin, nəticəni linzasız baza ilə iki cür müqayisə edin: eyni işıqtoplama sahəsi və eyni fotoelement sahəsi. Hazır kataloqda xətti Fresnel (LFS150150), nöqtə fokuslu Fresnel, qabarıq və mənfi linza, düz örtük və CPC reflektoru var; kataloqdan kənar linzanı əl ilə daxil edib bu brauzerdə yadda saxlamaq olar. Hər parametrin statusu göstərilir: istehsalçı məlumatı, ölçülüb və ya fərziyyə.

Ani hesab

İllik hesab: seçilmiş məlumat dəsti

    Xüsusi hal: 144 hüceyrəli PV panel üstündə linza (hüceyrə səviyyəsində model)

    Aşağıdakı bölmə əvvəlki linza laboratoriyasıdır: Trina panelinin real hüceyrə xəritəsi, hüceyrələr arası boşluqlar, modul şüşəsində sınma, bypass diodları və hüceyrə I–V modeli ilə.

    Linzanın gücü

    f = 1/D metr. D = 0: düz təbəqə, işığı yığmır. D > 0: toplayıcı linza, real fokus. D < 0: səpələyici linza, fokus xəyalidir (linzanın üstündə), şüalar açılır.

    Linza ilə hüceyrə müstəvisi arası məsafə h

    Hüceyrələr 1,6 mm şüşə və ~0,5 mm laminat altındadır, ona görə h ≥ 2,6 mm. Şüşədə şüalar Snell qanunu ilə sınır.

    İl ərzində, linzasız—kWh/m² apertura (brüt DC)

    Hesab üsulu: linza və “boş linza” (n = 1, ötürmə 100%, D = 0) eyni optik zəncirdən keçirilir. Onların nisbəti pvlib baza ssenarisi A-ya tətbiq olunur. Elektrik: hüceyrə xəritəsindən sürətli “ən zəif hüceyrə” qaydası (T1 topologiyası). Hüceyrə I–V modeli ilə yoxlama aşağıdakı cədvəldədir.

    Tələb olunan sınaqlar: +3, −3, +10, −10 D

    Sınanmış diapazonda ən yaxşı linza massivi

    Elektrik modeli: sürətli qayda ↔ hüceyrə I–V modeli

    Növbəti dəqiqlik səviyyəsi: Snell/Fresnel şüa izləməsi ↔ paraksial model

    2D izləmə maililik istiqamətindədir. Sferik plan-qabarıq (D > 0) və ya plan-çökük (D < 0) linza götürülür, əyri tərəfi Günəşə baxır, R = (n − 1)·|f|. Günəş diski ±0,27° ilə nümunələnir. Real linza profili məlum olmadığı üçün bu profil fərziyyədir.
